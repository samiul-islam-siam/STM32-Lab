# 🔬 STM-32 Experimental Branch

A collection of STM32 experiments, peripheral tests, and embedded system practice projects.


## 📂 Experiments

| File | Description |
|------|-------------|
| `External_LED_Blink.c` | External LED blinking test |
| `LED_Blinking_by_USART.c` | LED control using USART |
| `Morse_Code.c` | Morse code using push button |
| `PWM_Output_D7.c` | PWM output on PA8 (D7) |
| `Sound_Intensity.c` | Sound intensity detection |
| `WS2812B.c` | WS2812B LED with brightness control |
| `WS2812B_NOP.c` | WS2812B driver using NOP timing |



## 📌 About This Branch</summary>

This branch is used for testing new ideas, learning embedded systems concepts, and experimenting with STM32 peripherals and hardware-level programming.
